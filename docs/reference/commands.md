| Command | Description | Permission |
|---|---|---|
| `/rexkills` | Show help | everyone |
| `/rexkills help` | Show help | everyone |
| `/rexkills reload` | Reload `config.yml` | `rexkills.reload` |
| `/rexkills preview <cause> [killer]` | Print one death line to yourself | `rexkills.preview` |

Aliases: `/rxk`, `/kills`

The preview cause is a damage cause name, such as `fall` or `ENTITY_ATTACK`. Tab completion lists them.

Help text comes from `messages.help-header` and `messages.help`.
