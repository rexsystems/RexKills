| Java | 21 |
| Server | Paper, Purpur, or Folia 1.21 or newer |
| Optional | PlaceholderAPI |

The death-screen modes `custom` and `hide` need a Paper build that has `deathScreenMessage`. Paper 1.21.1 does not. On that build the chat line still changes, and the respawn screen stays vanilla. Set `settings.death-screen` to `keep` unless you are on a build that supports it.
