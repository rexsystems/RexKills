---
title: Installation
description: Put RexKills on a Paper, Purpur, or Folia server.
sidebar:
  order: 1
---

1. Download the jar.
2. Put it in the server `plugins/` folder.
3. Start the server once so `plugins/RexKills/config.yml` is written.
4. Edit the file.
5. Run `/rexkills reload`, or restart.

PlaceholderAPI is not required. If it is installed when RexKills enables, the `%rexkills_...%` placeholders register on their own.
